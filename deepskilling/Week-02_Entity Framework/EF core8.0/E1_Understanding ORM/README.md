# Lab 1: Exploring ORM Using a Retail Inventory Management System

## Objective

Develop a retail inventory application that manages product details, product categories, and stock quantities using SQL Server.

## What Was Covered

- Demonstrates how Object-Relational Mapping (ORM) connects C# objects with relational database tables.
- Highlights the advantages of Entity Framework Core, including improved developer productivity, easier maintenance, and simplified database interactions without writing raw SQL.
- Describes the key differences between Entity Framework Core and the traditional Entity Framework.
- Discusses major features introduced in EF Core 8.0, such as JSON column support, compiled models, interceptors, and enhanced bulk operation performance.
- Configures the console application and includes the required EF Core package references through the module-level project configuration.
