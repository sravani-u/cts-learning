# Lab 6: Updating and Removing Records with Entity Framework Core

## Objective

Modify existing product information and remove discontinued items from the retail inventory database using Entity Framework Core.

## What Was Implemented

- Updated the **Laptop** product price to **70,000**.
- Deleted the **Rice Bag** product from the database.
- Persisted each modification by calling `SaveChangesAsync()`.
- Demonstrated EF Core operations for updating and deleting records efficiently.

## Run the Application

```powershell
dotnet run --project .\Lab06-Update-Delete.csproj
```
